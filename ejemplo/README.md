# Ejemplo

`informe-ejemplo.md` es la salida real de `python eval.py evaluar --modelo claude-sonnet-5-5` sobre tres aplicaciones de
e-commerce (N1, N2 y N3) generadas con las especificaciones de `especificaciones/`, el 2026-10-13.

Sirve para ver el formato del informe, no como resultado a citar:

- Los rangos siguen abiertos (la revisión manual no se había completado).
- El modelo generador (`claude-sonnet-5-5`) se asumió igual al de la sesión; no se verificó.
- Una sola corrida por nivel y sin ejecutar las aplicaciones contra MongoDB. Vea [../docs/limitaciones.md](../docs/limitaciones.md).
